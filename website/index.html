Frequently asked

Is YuviXterm a MobaXterm alternative for Mac?

Yes. MobaXterm is Windows-only. YuviXterm brings the parts Mac users miss most — a saved-host sidebar, tabbed SSH terminals, and a live remote resource monitor — to a native macOS app, and the same app now runs on Windows too.

Does it run on Windows?

Yes — Windows 10 and 11 (64-bit). Download the installer (per-user, no admin rights needed) or the portable .exe. Saved logins are encrypted with Windows DPAPI.

Is it really free?

Yes, YuviXterm is free to download and use on macOS and Windows. No account, no subscription.

Does it run on Apple Silicon?

Yes — Apple Silicon (M-series) and Intel Macs, macOS 11 Big Sur or later.

Where are my passwords stored?

Encrypted with the operating system's secure storage — the macOS Keychain or Windows DPAPI (via Electron's safeStorage) — and never written to disk in plaintext. SSH keys, key passphrases and the ssh-agent are supported too.

macOS says it can't verify the developer — how do I open it?

On first launch, right-click the app in Finder and choose Open, then Open again. macOS remembers the choice from then on.

Windows SmartScreen says the app is unrecognized — how do I run it?

The build is unsigned, so SmartScreen may show "Windows protected your PC" the first time. Click More info, then Run anyway.

Can I transfer files (SFTP)?

Yes — a dual-pane SFTP file browser is built in. Open it with the Files button and move files between your computer and the server (drag or double-click) over the same connection. X11 and port forwarding aren't included yet.
